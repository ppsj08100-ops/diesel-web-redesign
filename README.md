# DIESEL — For Successful Living

Figma `BLACK` 시안을 HTML, CSS, JavaScript로 구현한 정적 사이트입니다. 프레임워크와 설치할 의존성이 없습니다.

## 파일

- `index.html`: 전체 화면과 상세 보기 콘텐츠
- `styles.css`: 로컬 웹폰트, 디자인 토큰, 데스크톱·모바일 스타일
- `app.js`: 캐러셀, 메뉴, 상세 보기, 선언문·철학 스크롤 효과, 상단 이동
- `story-background.js`: 선언문·철학 배경의 출렁임과 감쇠
- `lookbook-scroll.css`, `lookbook-scroll.js`: 패션 사진 자동 시퀀스와 가방 섹션 연결
- `bags-scroll.css`, `bags-scroll.js`: 고정된 가방 화면의 스크롤별 상품·타이포 전환
- `bag-photo-transition.js`: 상품 사진의 중앙 슬릿 마스크 전환
- `commitment-journey.css`, `commitment-journey.js`: 세 타이포 챕터의 입체 공간 이동·절개·조명
- `badlands-motion.css`, `badlands-motion.js`: 고정된 사진 프레임과 세로 스크롤을 이용한 BADLANDS 장면·타이포 전환
- `footer-physics.js`: 오벌 D 메탈 배지의 불규칙한 쌓임·잔잔한 움직임과 포인터 상호작용
- `cta-unified.css`: 전 섹션 VIEW MORE의 실제 화면 크기 통일
- `collection-hover.css`: MEN·WOMEN 사진 위의 VIEW MORE와 확대 사진 보기
- `assets/`: Figma 원본 이미지·SVG와 로컬 웹폰트
- `styleguide.md`: 원본 스타일 명세
- `asset-manifest.json`: 이미지 출처 노드와 파일 크기

## 실행

`index.html`을 브라우저에서 열면 실행됩니다. HTTP 미리보기가 필요한 경우 사이트 파일만 복사한 배포 디렉터리를 사용합니다.

```sh
node .openai/build.mjs
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

브라우저에서 `http://127.0.0.1:4173`에 접속합니다.

## 동작

BAGS와 BADLANDS는 고정된 화면에서 세로 스크롤로 장면을 전환합니다. VIEW MORE, EXPLORE 및 MEDIA 이미지는 상세 보기를 엽니다. 상세 보기는 닫기 버튼·Escape·배경 클릭으로 닫힙니다. 상단 주 메뉴와 푸터 링크는 각 섹션으로 이동하며, 900px 이하에서는 MENU 버튼으로 주 메뉴를 펼칩니다. 검색 아이콘은 사이트 내 컬렉션과 콘텐츠를 검색합니다.

선언문의 FOR·SUCCESSFUL·LIVING은 줄마다 차례로 나타나며, 폭 768px·높이 600px 이상에서는 스크롤 50svh 동안 화면에 고정한 뒤 위로 이동하며 사라집니다. 이어 PHILOSOPHY 라벨·제목·설명·버튼이 순서대로 나타납니다. 모바일과 높이 600px 미만 화면에서는 고정 없이 진입 효과만 적용하며, 동작 줄이기 설정에서는 두 섹션을 정적으로 표시합니다. PHILOSOPHY의 VIEW MORE는 마우스 오버·키보드 포커스 시 원형 배경이 디젤 레드로 바뀌고 화살표가 오른쪽으로 이동합니다.

사용자 요청으로 선언문 상단의 SINCE 1978·RENZO ROSSO’S MANIFESTO는 하단 보조 문구와 동일한 Hagrid Light 300을 사용합니다. 선언문과 철학 배경은 [SAKAZUKI](https://sakazuki.io/)를 참고해 기존 검정 데님 이미지를 30% 농도로 은은하게 사용하며, 철학에서는 좌우를 반전합니다. 화면 중앙의 섹션이 바뀔 때만 배경이 2.4초 동안 부드럽게 굴절되고 두 겹의 질감이 섞이며 정착합니다. 같은 섹션 안의 스크롤로 전환을 반복하지 않으며, 글자와 버튼은 선명하게 유지합니다. 모바일에서는 움직임을 줄이고, 정착 후·화면 밖·비활성 탭에서는 렌더링을 멈춥니다. 동작 줄이기 설정이나 WebGL 미지원 환경에서는 정적 배경을 표시합니다.

히어로는 [Figma Hero1 (`1128:245`)](https://www.figma.com/design/6GPeNKxLjIVbw8NeE8h3xO/?node-id=1128-245)의 영상과 문구를 사용합니다. 원본 영상 `assets/hero-1128.mp4`는 `1232×736px`, 약 `15.042초`이며 Figma의 영상 해시와 일치하는 파일입니다. 데스크톱에서는 1920×1080 기준으로 영상·제목·카피·내비게이션을 함께 축소하고, 16:9 화면 전체를 `object-fit: cover; object-position: center`로 채웁니다. 흰색 DIESEL 제목은 `74px, 570px`, Hagrid Light `300px`, 자간 `-6px`이며 D는 이탤릭입니다. 검정색 3줄 카피는 `87px, 826px`, Hagrid Text Regular `24px / 31.2px`이며 첫 줄 앞 공백 11개를 유지합니다.

영상은 음소거·자동 재생·반복·인라인 재생으로 설정하고, 메타데이터만 미리 로드하며 Figma의 원본 포스터 `assets/imgHeroVideoPoster.png`를 함께 사용합니다. 우측 하단 PAUSE/PLAY 버튼으로 재생을 제어할 수 있습니다. 동작 줄이기 설정에서는 자동으로 재생하지 않으며 사용자가 PLAY를 눌러 재생할 수 있습니다. 화면 밖이나 비활성 탭에서는 멈추고, 사용자가 직접 일시정지한 영상은 자동으로 다시 재생하지 않습니다. 자동 재생이 차단되면 PLAY를 표시하고 영상 오류 시 포스터를 유지합니다. 기존 정적 사진의 국소 명암 보정은 사용하지 않습니다. 900px 이하에서는 흰색 MENU 헤더, 화면을 채우는 영상과 하단 왼쪽 제목·카피 배치를 사용합니다.

메뉴 순서는 BAGS, COMMITMENT, BADLANDS, FOOTAGE, PRESS, MEN, WOMEN이며 데스크톱의 7개 메뉴 글자는 모두 검정색입니다. 원본 윤곽을 유지한 아이콘 4개를 사용하며, 사용자 요청으로 메뉴 글자와 획 두께가 어울리도록 약 1.5px로 보강했습니다. MY DIESEL과 위시리스트는 공식 사이트를 새 창으로 열며, 가방 아이콘은 이 페이지의 가방 컬렉션으로 이동합니다.
